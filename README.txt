나만의 가계부 PWA v2

추가 기능
- 카테고리 삭제
  * 사용하지 않은 카테고리: 바로 삭제 가능
  * 이미 사용한 카테고리: 기존 내역을 '기타'로 이동 후 삭제
- CSV 가져오기
  * 필수 열: 날짜, 금액, 카테고리, 결제수단
  * 선택 열: 내용
  * 날짜 형식: 2026-08-12 또는 2026.08.12 또는 2026/08/12
  * 결제수단은 앱에 있는 이름(내 신용카드 / 엄마카드 / 계좌이체)과 같아야 함
  * 새 카테고리는 가져오면서 자동 추가
- CSV 입력 양식 다운로드

엑셀에서 입력한 파일은 'CSV UTF-8(쉼표로 분리)' 형식으로 저장한 뒤 가계부의 설정 > 데이터 > CSV 가져오기에서 선택하세요.

v1과 같은 localStorage 키(jihyeonBudgetV1)를 사용하므로 같은 Netlify 사이트에 덮어 업로드하면 기존 데이터가 유지됩니다. 그래도 업데이트 전 JSON 백업을 권장합니다.
